# Capture8K

Capture the visible web page in 4K or 8K on macOS with Chrome or Firefox. Capture8K preserves the page’s proportions and checks the result before saving it as a PNG. It can also send the PNG to the active Premiere Pro project through Creator Bridge.

[Download the latest release](https://github.com/Coraubanne/Capture8K/releases/latest) · [French documentation](README.md) · [Changelog](CHANGELOG.md)

Open the release ZIP and run `./install-macos.sh` from the extracted folder. In Chrome, use **Load unpacked** in `chrome://extensions` and choose `~/Documents/Capture8K/Chrome`. Run the installer again with the extension ID shown by Chrome to connect it to the Mac app. In Firefox, use `about:debugging#/runtime/this-firefox` to load `~/Documents/Capture8K/Firefox/manifest.json` as a temporary add-on.

Use **Settings → Check for updates** in either extension after installation.
