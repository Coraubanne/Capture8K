Capture8K relit désormais la version installée sur le Mac à chaque recherche. Quand le navigateur garde sa connexion au compagnon après une mise à jour, Capture8K reconnaît la version installée et évite de la télécharger à nouveau.

## English

Capture8K reads the installed version from disk when checking for updates. An existing browser connection no longer causes the same version to be offered again.
