# Capture8K 2.9.0

Téléchargez `Capture8K-complet-v2.9.0.zip`. L’archive réunit le compagnon macOS, les extensions Chrome et Firefox et Creator Bridge 1.1.0.

- La recherche de mise à jour propose aussi Creator Bridge lorsque la destination active est Premiere Pro.
- Capture8K et ClipFlow coordonnent l’installation du plugin partagé pour conserver la version la plus récente.
- Dans Firefox, chargez le manifeste du dossier `Documents/Capture8K/Firefox` comme module temporaire. Firefox retire cette installation au redémarrage.

## English

The complete macOS ZIP includes both browser extensions and Creator Bridge. When Premiere Pro is selected as the destination, either browser can check for a standalone Creator Bridge update.
