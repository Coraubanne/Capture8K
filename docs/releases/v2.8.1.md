# Capture8K 2.8.1

Le dépôt public Capture8K réunit désormais le code, la documentation, les téléchargements et les mises à jour.

Le ZIP contient le compagnon macOS précompilé, les extensions Chrome et Firefox, Creator Bridge et le script d’installation. Le fichier SHA-256 permet de vérifier l’archive.

Depuis la 2.8.0, ouvrez **Réglages → Chercher une mise à jour** pour migrer vers le nouveau dépôt. Après l’installation, rechargez Capture8K dans Chrome et Firefox. Le module Firefox reste temporaire.
